# 参考图

这 8 张参考图都是用本 skill 生成的示范，素材来自 Unsplash（Unsplash License：可免费使用和修改，无需署名）。每张对应一个模板或手法，文件名第二段是手法类别。

生成前：按本页照片的情况挑 1–2 张最接近的图 Read 一下，不要每次全部打开。只学构图、图层关系、色调和装饰密度，不照抄具体元素。

## 通用风格

- 真实照片是主体，占画面绝大部分；装饰只是点缀。
- 常见结构：一张大底图 + 一张大照片 + 2–3 张小图；小图多是植物、花、蘑菇、小物件的近景，和人物照形成远近对比。
- 主要装饰：点阵纹理、白色或浅色细线手绘藤蔓、少量光滴和闪光。
- 人物照用浅一些的明亮滤镜，景物照保持深一点、绿一点，深底衬浅图，层次更清楚。
- **一页只用一个色系：** 森林绿配淡粉、蓝天配绿草都和谐；暖金夜景、日落粉橙和森林冷绿混在同一页会撞色，不要放在一起。

## 每张学什么

### ref_split_forest-moss.jpg（A 上下软拼接）
上半是林间低头的女孩，下半是苔藓和小红蘑菇，渐变过渡没有直线接缝；她像在低头看那朵蘑菇，故事连贯。橙蘑菇圆图压在接缝上，左下蕨芽拱门用藤蔓往上连。
学：同一场景的人物远景 + 景物近景上下拼接；小图压接缝。

### ref_fade_sky-flowers.jpg（B 叠印过渡）
上半蓝天、下半花丛，中间大范围渐变融合；人像放进拱门框，跨在两张图的交界处；藤蔓分别连到云朵圆图和花丛。
学：两张场景照柔和融合成一个空间，主图跨过交界。

### ref_overlap_moss-fiddlehead.jpg（C 大块叠放）
苔藓地面作满版底；林间女孩和嫩蕨芽两张大矩形错位压角；左下橙蘑菇虚线圆图；藤蔓连接各张。
学：有质感的植物近景当底，大块照片错位叠放，全页同一森林绿。

### ref_scatter_moss-mushroom.jpg（D 框图散点）
苔藓地面作底；人像、橙蘑菇圆框、蕨芽椭圆框沿对角线散开，一条长藤蔓串起三张。
学：小图分散在不同高度，用线条连接而不是各占一格。

### ref_hang_star-bunny.jpg（E 风铃悬挂）
深色花丛作底；星灯圆图用金线从上沿垂下，藤蔓连到人像；兔子图压住人像一角。
学：本来就是挂件的物体用细线挂下来；深底衬浅图。

### ref_orbit_fern-forest.jpg（F 主图环绕小圆）
嫩绿蕨芽虚化作底；林间女孩是虚线框主图；橙蘑菇、苔藓红蘑菇、蕨叶三个小圆环绕，底部藤蔓连接两个小圆。
学：同色系背景虚化后衬主图；小圆分主次、分高度。

### ref_blend_flowers-bunny.jpg（G 叠印融合）
深色花丛作底，兔子所在的雏菊草地从下方渐变融进来；藤蔓从星灯连到人像、从人像连到兔子。
学：第二张场景照局部叠进底图；叠印要实，不做成半透明重影。

### ref_thread_flowers-star.jpg（J 线索串联）
深色花丛作底；一条长藤蔓从画布左边进来，依次经过人像、兔子、星灯，再从底边出去。
学：一条线把几张小图按顺序串起来，线色取自照片。

## 生成后自查（6 类常见问题）
1. **无关照片硬拼：** 拼成大方块，没有呼应或过渡。无关场景可以同页，但要说得出联系，并且让它当细节小图，不抢主图。
2. **重复照片：** 同构图、同表情的只用最好的一张。
3. **主次错乱：** 物件比人大，小图压在人身上。
4. **色调灰、雾、黄、荧光，或冷暖色系撞色：** 和明亮清透、单一色系相反。
5. **装饰的三种失败：** 没锚点飘在空中；堆在一个角；用了实心主题元素、自编文字或意义不明的色块。
6. **叠印做成重影。**
